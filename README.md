# Colchones Leos — Publicación en Render

1. Descomprime el ZIP.
2. Crea un repositorio de GitHub llamado `colchones-leos`.
3. Sube la carpeta `dist`, `render.yaml` y este README a la raíz del repositorio. Sube los archivos descomprimidos, no el ZIP.
4. En Render: New > Static Site. Conecta el repositorio.
5. Usa estos valores:
   - Name: colchones-leos
   - Branch: la rama en la que subiste los archivos, normalmente main
   - Root Directory: dejar vacío
   - Build Command: true
   - Publish Directory: dist
6. Create Static Site.

También puedes usar New > Blueprint y seleccionar el repositorio; `render.yaml` contiene la configuración.

## Google
Cuando Render te entregue la URL definitiva, ajusta la URL canónica y genera un sitemap para esa dirección. Esta copia no apunta al dominio anterior de ChatGPT. Después verifica la propiedad en Google Search Console y solicita indexación.
